# Data

This directory contains derived data only:

* `hwdb/` — indices of the HWDB-LT / HWDB-NAT / flip / dose training splits and their
  summaries, plus the 3,755-class list;
* `bctr/` — the BCTR training character-frequency table used to rank classes.

No raw images, labels or competition annotations are redistributed. See
[`docs/data.md`](../docs/data.md) for the meaning of each file, how the splits were
built, and where to obtain the upstream datasets.
